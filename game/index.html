Sensor layout

Firmware contract

In LIVE mode the bridge (python molefield.py) listens for ESP32 sensor boxes on UDP :5000 and forwards merged frames to this page over WebSocket. It accepts the deployed test firmware's plain-text datagrams: 

Box:1,S1:120.5,S2:115.2

(Sn values are centimetres to the nearest surface; -1 means no echo.) It also accepts the JSON format from firmware/molefield_sensor.ino: 

{ "box": 0,
  "t": 184213,
  "ranges": [1420, 1655] }

Box 1 is the left-hand box (slots S0, S1) and Box 2 is the right-hand box (slots S2, S3). Within each box, S1 is the outer sensor and S2 the inner, splayed one. Frames older than 400 ms are treated as stale.
